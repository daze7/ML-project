# House Price Regression

Учебный ML-проект по прогнозированию стоимости недвижимости на основе характеристик объектов.

## Цель проекта

Цель проекта — исследовать задачу регрессии и сравнить разные модели машинного обучения для предсказания цены недвижимости.
В проекте рассматриваются этапы предобработки данных, очистки выбросов, кодирования признаков, масштабирования, обучения моделей и оценки качества.

## Данные

В проекте используется датасет с информацией о недвижимости: площадь, количество комнат, количество ванных комнат, балконов, тип площади, локация и цена объекта.

Файл с данными должен находиться в папке:

```text
data/Pune house data.csv
```

## Что было сделано

* Проведён первичный анализ данных.
* Удалены нерелевантные признаки.
* Обработаны пропуски и некорректные значения.
* Преобразованы текстовые признаки в числовой формат.
* Проведена очистка выбросов.
* Выполнено масштабирование признаков.
* Данные разделены на обучающую и тестовую выборки.
* Обучены и сравнены несколько моделей регрессии.
* Качество моделей оценивалось с помощью RMSE и кросс-валидации.
* Построены кривые обучения для анализа переобучения и недообучения.

## Использованные модели

* Linear Regression
* Polynomial Regression
* SGDRegressor
* Decision Tree Regressor
* Random Forest Regressor
* AdaBoost Regressor
* Support Vector Regression
* Ridge Regression

## Основной вывод

В ходе проекта были сравнены разные подходы к решению задачи регрессии. Простые модели могут давать стабильный результат, но часть моделей склонна к недообучению, а более сложные модели могут переобучаться. Проект показал важность качественной предобработки данных, выбора метрик и анализа поведения модели на обучающей и тестовой выборках.
